# SwarmBox

**一个不可逃逸、可复跑的多智能体测试床。**
为 Swarm Alignment Hackathon 2026 的 Track 1（沙箱与测试床）而建。

> 这个盒子里的智能体出不去 —— 而且我们能给你看凭证。

完整报告见 **[REPORT.md](REPORT.md)**，本文件是操作手册。

## 核心思路

这个沙箱**不是解释器**。智能体的输出被当作**数据**解析，从不求值。因此文件系统、
网络、子进程、import、反射这些逃逸手段不是"被拦截"，而是**根本不在语法里**，
无法被请求。剩下的只有六种操作，每一种在触碰世界之前都要过 schema 校验和资源校验。
每一条提案 —— 包括每一条被拒绝的 —— 都会写进只追加的账本，所以"不可逃逸"这个
结论是可审计的，而不是需要被相信的。在此之上是一个小型公共资源池经济：5–20 个
智能体在多轮中取用一份可再生资源，指标会告诉你它们是协作、合谋，还是把它吃空。

## 快速开始

```bash
python eval.py              # 235 条断言，0 失败（含完整攻击语料）
python -m swarmbox gate     # 32 种逃逸尝试，逐条被拒并给出规则 ID
python -m swarmbox run      # 跑一个混合种群
python -m swarmbox probe    # 植入的合谋对，仅从账本视角能否发现
python -m swarmbox fidelity # 廉价 vs 前沿，8 个种子
```

Python 3.9+，**零第三方依赖、零网络**。`git clone && python eval.py` 就是全部安装步骤。

## 架构

```
智能体策略 ──▶ 提案 ──▶ 闸门 ──▶ 世界 ──▶ 账本（只追加 JSONL）
                          │                  │
              结构/身份/状态三重校验      指标、复跑、审计线索
              每次拒绝都留痕
```

| 模块 | 职责 |
|---|---|
| `gate.py` | 六种操作、严格 schema、20 个稳定规则 ID、32 条攻击语料 |
| `world.py` | 公共资源池、私有单元、共享暂存区、不变量 |
| `agents.py` | 8 个确定性策略，分属两个家族（廉价 / 前沿） |
| `swarm.py` | 轮次循环；一次运行是配置的纯函数 |
| `ledger.py` | 只追加 JSONL；拒绝是一等记录 |
| `metrics.py` | 基尼、超额索取、漂移、崩溃、相关性、隐蔽信道计数 |
| `fidelity.py` | 廉价 vs 前沿实验 |
| `probe.py` | 植入合谋对实验 |

## 三层围堵

| 层 | 拦住什么 |
|---|---|
| 结构层（不在语法里） | 文件系统、网络、进程、import、反射 |
| Schema 层（严格、禁止未知字段） | 夹带、类型混淆、冒充 |
| 状态层（对照世界校验） | 超额索取、超额释放、保留命名空间 |

每次 `apply()` 之后都会重算的不变量：

```
存量池 + 累计索取 == 累计注入     存量池 >= 0     每个持仓 >= 0     存量池 <= 容量
```

一个真能逃逸的智能体几乎必然要凭空造出资源单位 —— 而那会先破坏算术。
不变量是绊线，闸门是围栏。

## 可复跑性

一次运行是 `(seed, n, rounds, capacity, regen, roles)` 的纯函数。相同输入 → 账本
摘要逐字节相同（`eval.py` 对种子 1–5 均有断言）。账本第一行记录完整配置，所以
把账本交给别人，他就知道该重跑什么。

## 诚实声明

本项目**不**主张以下几点：

* **全程没有调用任何语言模型。** 八个策略都是纯函数。廉价/前沿的结论是关于
  **信息集**的实验，不是对真实模型的基准测试。
* **逃逸只在动作语言内部被拒绝。** 我们主张的是该语言无法表达逃逸；我们不是通用
  代码执行沙箱，也不声称能抵御那种攻击面。
* **闸门是静态检查，不是运行时沙箱。** 它成立的原因是 SwarmBox 根本没有通往宿主
  的路径，而不是因为它扛得住运行时的蓄意攻击。
* **合谋检测基于相关性。** 它能抓到轮流式合谋，抓不到更精巧的合谋。
